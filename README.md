# 📻 Purane Gaane – Old Saloon Playlists

A nostalgic music website featuring classic songs and collections for
truck drivers, salon environments, romantic moments, and old memories.

## 🌐 Live Website

https://suryakumar-git654.github.io/Old-saloon-playlists/

## ✨ Features

- 🎵 Music player
- ▶️ Play / Pause songs
- ⏮️ Previous and ⏭️ Next controls
- 🔊 Volume control
- 📊 Song progress bar
- ❤️ Favorite songs
- 🕘 Recently played songs
- 🔍 Song search
- 🚛 Truck Driver category
- 💈 Salon Classics category
- ❤️ Romantic Songs category
- 😢 Sad Songs category
- 📱 Responsive design

## 🎵 Songs

The project currently contains four test audio files:

1. Highway Memories
2. Salon Classics
3. 90s Memories
4. Dil Se Purane
